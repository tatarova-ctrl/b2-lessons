STEP 05 · GRAMMAR FOCUS📝 The third conditional

⚖️ Talking about an imaginary past

  • For the past that did NOT happen — regrets and imagined results.
  • Form: If + past perfect, would have + past participle.
  • If he had told the truth, the judge would have been kinder.
  • Halves can swap: The burglar wouldn't have got in if they had locked the door.
  • Other modals: could have, might have.
IF + had + p.p. , WOULD HAVE + p.p.

STEP 05 · GRAMMAR FOCUS📝 Reported questions

📰 Turning questions into statements

  • Statement word order — no inversion: "Where is it?" → She asked where it was.
  • No do / does / did: "Where do you live?" → He asked where I lived.
  • Yes/no → if or whether: "Are you ready?" → She asked if I was ready.
  • Tenses shift back: is→was, do→did, have→had, will→would.
"Do/Are you …?" → asked IF/WHETHER + I + past verb

STEP 05 · GRAMMAR FOCUS📝 used to / would / be used to

👨‍👩‍👧 Three look-alikes — keep them apart!

  • used to + verb = past habit/state not true now: We used to live abroad.
  • would + verb = repeated past action (NOT states): Every weekend we would walk to the market.
  • be used to + noun / -ing = be accustomed to (now): I'm used to sharing a room.
  • get used to + -ing = become accustomed: I soon got used to having a baby sister.
past habit/state → USED TO + verb · accustomed now → BE USED TO + -ing

STEP 05 · GRAMMAR FOCUS📝 Articles: a / an / the / —

🔭 When to use each one

  • a / an = one of many, first mention: a planet, an experiment. Use an before a vowel sound.
  • the = specific, already mentioned, or unique: the Sun, the Moon, the universe.
  • No article (—) with plural/uncountable nouns in general: Scientists do research. Gravity is invisible.
  • No article with most names: Earth, Mars, Einstein.
first/one of many → A/AN · unique → THE · general plural/uncountable → —
