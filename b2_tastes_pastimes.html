STEP 05 · GRAMMAR FOCUS📝 Quantifiers

🍳 How much / how many?

  • some = positive sentences & polite offers/requests · any = negatives & questions: I have some milk. I don't have any milk. Do you have any?
  • many = countable (eggs, tomatoes) · much = uncountable (milk, sugar). Both are common in negatives/questions.
  • a lot of / lots of = both, mainly positive: lots of tomatoes, lots of salt.
  • a few = a small positive number (countable) · a little = a small positive amount (uncountable).
  • few / little (without a) = almost none — negative feel.
countable → MANY / A FEW · uncountable → MUCH / A LITTLE
positive → SOME / LOTS OF · negatives & questions → ANY

STEP 05 · GRAMMAR FOCUS📝 wish / if only

⚽ Three patterns for regrets and dreams

  • wish + past simple = wish about now (unreal present): I wish I were taller. I wish I had more time.
  • wish + past perfect = regret about the past: I wish I had trained harder before the final.
  • wish + would = annoyance / want someone else to change: I wish you would stop shouting!
  • if only works the same way as wish, only more emphatic.
  • Use were for all persons after wish/if only: I wish I were…
unreal NOW → wish + past simple (were / knew / had)
regret PAST → wish + had + p.p. · annoyance → wish + would

STEP 05 · GRAMMAR FOCUS📝 Linking words

🎵 Joining ideas: contrast · reason · purpose · result

  • Contrast + clause: although, even though, though, while, whereas → Although it was raining, we went.
  • Contrast + noun / -ing: despite, in spite of → Despite the rain, we went.
  • Reason + clause: because, since, as · + noun: because of, due to.
  • Purpose: to / in order to / so as to + verb · so that + clause → I trained hard so that I could win.
  • Result: so, therefore, as a result → It was loud, so we left.
contrast + clause → ALTHOUGH · contrast + noun → DESPITE
reason + noun → BECAUSE OF · purpose → IN ORDER TO / SO THAT

STEP 05 · GRAMMAR FOCUS📝 The causative — have / get something done

👗 When someone else does it for you

  • Use it when you arrange for someone else to do a job for you.
  • Form: subject + have / get + object + past participle.
  • I cut my hair. = I did it myself. I had my hair cut. = the hairdresser did it.
  • get is a bit more informal than have: I'm getting my car washed.
  • Works in any tense: had it done, will have it done, am having it done.
HAVE / GET + object + past participle
I had my dress ALTERED · We're getting the car FIXED
